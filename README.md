Comic book reader

Een comic book reader gemaakt voor Periode 1, jaar 2, HBO-ICT op het NHL-STENDEN

De functies zijn:
- comics openen 
- in en uit zoemen
- metadata bekijken en bewerken
- annotaties maken
- comicbibliotheek waar je alle comics ziet die je ooit hebt geopend, met de eerste pagina als thumbnail en wat standaard metadata
- verdergaan waar je was gebleven
- zoek en sorteer functies
- meerdere talen beschikbaar

Voer Main uit, Main bevindt zich in src/main/java/com/alba<br>
